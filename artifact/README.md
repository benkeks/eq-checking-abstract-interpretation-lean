# Using the Artifact

## Prerequisites

The artifact requires Docker and Bash. It was prepared with Docker 28.5.2 on Linux.

## Loading / building the image

If you posses the artifact image, you can load it from a tarball using:

```bash
docker load -i eq-checking-abstract-interpretation-lean-image.tar
```

Otherwise, build the image from the repository root (this might take some time to pull and build mathlib dependencies):

```bash
docker build -t eq-checking-abstract-interpretation-lean .
```

The image uses Lean `v4.34.1`, the version pinned by the repository, and builds the formalization during image creation. Sorry, it's more than 10 GB as the packaged Mathlib dependencies are quite large.

## Checking the formalization

To check the formalization, run the Lean build inside the image:

```bash
docker run --rm eq-checking-abstract-interpretation-lean lake build
```

If you want to perform a full clean build (which might take about 5–20 minutes for a Mathlib rebuild), run:

```bash
docker run --rm eq-checking-abstract-interpretation-lean bash -c 'lake clean && lake build'
```

Each fact in the paper comes with a link to the respective fact in the formalization. Both usually align closely, with the Lean definitions allowing additional parameters that increase reusability or give explicit context.

## Running benchmarks

To test that the output matches expectations for examples from the linear-time--branching-time spectrum, run the executable interface regression tests:

```bash
docker run --rm eq-checking-abstract-interpretation-lean bash tests/main.sh
```

Run the LTBTS benchmark, which performs five shuffled rounds of the supplied examples, and print its CSV results (Table 1 in the paper):

```bash
docker run --rm eq-checking-abstract-interpretation-lean bash -c 'bash tests/ltbts1.sh && cat tests/ltbts1.results'
```

An example CSV file that has been generated by this script is to be found in `artifact/ltbts1.results.example`.

For your convenience, `artifact/ltbts1-equivio.csv` moreover packs a similar CSV from tests on the bigger strong spectrum on https://equiv.io.

For an interactive shell in the artifact, use:

```bash
docker run --rm -it eq-checking-abstract-interpretation-lean bash
```
